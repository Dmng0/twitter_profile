# 트친소 스튜디오

선택된 B안의 16:9 트친소 이미지 제작 도구입니다. 설치나 빌드 없이 실행합니다.

## 사용법

1. 압축을 풀고 `index.html`을 브라우저에서 엽니다.
2. 닉네임을 수정하고 왼쪽에서 필요한 태그를 선택합니다. 플랫폼과 NG는 직접 입력합니다.
3. 상단 배너와 네 개 캐릭터 칸의 `이미지 업로드` 영역을 클릭하거나, 파일을 해당 칸으로 드래그앤드랍합니다. 이미지를 넣은 뒤에도 같은 방법으로 교체할 수 있습니다.
4. 이미지 삭제와 세로 위치 조절은 왼쪽 사이드바에서 합니다.
5. 글자 색상과 배경 색상을 각각 현재 테마에 어울리는 24색 팔레트, 색상 선택기, HEX 코드로 지정합니다. 두 색상은 독립적으로 적용되며 PNG에도 반영됩니다.
6. `PNG 저장`을 누르면 1600×900 PNG 다운로드를 요청합니다.

지원 이미지: JPG, PNG, WebP, 파일당 20MB 이하. 배너와 캐릭터 칸은 기본적으로 비어 있습니다. 참고 이미지와 개인 프로필 이미지를 패키지에 포함하지 않았습니다.

하단 왼쪽은 비워두었으며, 오른쪽 `@Mmong404`는 구분선의 오른쪽 끝에 맞춰 #999999로 고정합니다. 이 색상은 글자색 선택기의 영향을 받지 않습니다.

입력 내용과 이미지는 브라우저에서만 처리합니다. 외부 라이브러리, 외부 폰트, API, 서버 저장 없이 실행합니다. 새로고침하면 편집 내용이 초기화됩니다. 긴 자유 입력은 두 줄까지 표시하고 넘치는 부분은 말줄임 처리합니다.

## GitHub Pages 게시

1. GitHub 저장소의 게시할 폴더에 `index.html`, `style.css`, `app.js`, `.nojekyll`을 함께 올립니다.
2. 저장소 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
3. 업로드한 브랜치와 폴더를 선택하고 Save를 누릅니다. 저장소 루트에 올렸다면 `/ (root)`를 선택합니다.
4. GitHub에서 게시 주소를 제공하면 해당 주소로 접속합니다.

정적 파일의 상대 경로를 사용하므로 저장소 하위 경로에서도 실행됩니다. 이 패키지를 실제 GitHub 저장소에 업로드하거나 게시하는 작업은 아직 진행하지 않았습니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 검증

Chrome에서 이미지 5칸 각각의 클릭 파일 선택, 업로드·삭제, 실제 File을 포함한 드래그앤드랍 이벤트를 검증했습니다. 닉네임/연령/색상/NG 변경, PNG 1600×900 데이터 생성과 다운로드 이벤트, 하단 문구·색상·우측 정렬을 확인했습니다. JavaScript 예외가 없었으며 390px 화면에서 문서 가로 넘침이 없었습니다.

자동화 브라우저의 파일 다운로드 완료는 확인하지 못했습니다. 다운로드 이벤트와 생성된 PNG 바이트까지 검증했습니다. 자세한 결과: `verification.json`.

상단 제목은 트친소이며, 내용과 이미지 위의 가로 구분선은 제거했습니다. 소개 정보와 캐릭터 영역을 위로 올리고 캐릭터 칸을 길게 확장해 여백을 조정했습니다.

배너 높이는 280px이며 권장 이미지 크기는 1600×280px입니다. 빈 배너의 이미지 업로드 문구 아래에 표시됩니다. 닉네임 아래 소개 문구는 삭제했습니다.
미리보기 오른쪽 위에서 −/＋ 버튼 또는 배율 선택으로 50~250% 확대·축소할 수 있습니다. 화면 맞춤은 가용 너비에 맞는 100%로 돌아갑니다. 확대 시 미리보기 안에서 가로·세로로 스크롤합니다. 미리보기에 키보드 초점을 두면 +, -, 0 키도 사용할 수 있습니다. 확대 배율과 관계없이 PNG는 1600×900으로 저장됩니다.

## 모바일 사용
900px 이하에서는 미리보기와 편집 항목을 위아래로 배치합니다. 상단의 미리보기/내용 편집 버튼으로 이동할 수 있고 PNG 저장 버튼은 스크롤 중에도 보입니다. 태그·색상 버튼은 최소 44px 터치 영역이며 입력 글자 크기는 16px입니다. 이미지 칸을 눌러 휴대폰의 이미지 파일을 선택하세요.
터치 기기에서 PNG 저장을 누르면 완성 이미지와 PNG 다운로드 링크가 있는 창이 열립니다. 다운로드 링크를 누르거나 이미지를 길게 눌러 저장 메뉴를 사용할 수 있습니다. 실제 저장 메뉴는 브라우저에 따라 다를 수 있습니다. 확대·축소 후 스크롤로 이미지를 확인할 수 있습니다.
휴대폰에서 접속하려면 GitHub Pages 등으로 게시한 HTTPS 주소를 사용하세요. PC의 file:/// 로컬 경로는 휴대폰에서 직접 열 수 없습니다. 아직 실제 게시 작업은 하지 않았습니다.
Chrome 모바일 에뮬레이션 320/390/768px에서 태그·색상 변경, 파일 선택, 200% 확대, 화면 맞춤, 저장 창, 다운로드 이벤트와 1600×900 이미지 생성을 확인했습니다. 실제 Android/iPhone 기기에서의 다운로드 완료는 확인하지 않았습니다.

캐릭터 4칸의 권장 이미지 크기는 각각 224×400px이며, 빈 칸의 이미지 업로드 문구 아래에 작게 표시됩니다. 같은 비율의 더 큰 이미지도 사용할 수 있습니다.


글자 색상과 배경 색상 제목 아래에 #666666 색상으로 색상 코드 입력 가능 안내를 표시합니다. 팔레트는 유채색과 무채색을 포함한 계통별 24색입니다. 빨강, 다홍, 주황, 노랑, 연두, 초록, 진초록, 청록, 하늘색, 파랑, 남색, 남보라, 보라, 자주, 분홍, 연분홍, 갈색, 황토, 베이지, 아이보리, 흰색, 연회색, 회색, 검정으로 구성되며 각 버튼에 색 이름과 HEX 코드를 표시합니다.
